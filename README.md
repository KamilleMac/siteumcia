# IA pode imitar seu parente

Site informativo sobre golpes com voz e rosto falsos feitos por inteligência artificial: como funcionam, como confirmar antes de pagar e o que fazer se o Pix já foi feito.

**Site no ar:** https://siteumcia.vercel.app

## Sobre o projeto

Trabalho da faculdade, feito como atividade de **horas de extensão**. O objetivo é ajudar a população, principalmente pessoas mais velhas, a reconhecer e evitar golpes digitais, com linguagem simples e visual fácil de entender.

- **Universidade:** Universidade de Mogi das Cruzes (UMC)
- **Curso:** Análise e Desenvolvimento de Sistemas
- **Turma:** Noturno, Turma 4 B, 2026
- **Professores responsáveis:** Bruno Messias Aguiar e Leandro Miranda de Almeida

## O que tem no site

- Como a IA copia voz e rosto, em 3 passos
- Sinais para desconfiar
- Como se proteger e passo a passo na tela para confirmar antes de pagar
- Como combater e como ajudar a família
- O que fazer se já fez o Pix
- "Entenda cada palavra": IA, voz falsa, deepfake, Pix, MED e palavra secreta
- Números oficiais de golpes digitais no Brasil
- Panfleto (frente e verso) para imprimir

## Tecnologias

HTML, CSS e JavaScript puros, sem bibliotecas. O site é responsivo (funciona no celular e no computador) e foi publicado na Vercel.

## Como ver no computador

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
